Student Innovation Project (SIP)

Remote Irrigation Well Control System

Project Overview

A LoRa-based remote irrigation-well shutdown-request prototype. Bench electronics are working; engine integration and field validation are still in progress.

Project Description

Problem: Traveling to an irrigation engine during lightning or severe weather creates avoidable exposure. Some locations also lack dependable cellular coverage.

Proposed solution: A direct LoRa link between a home touchscreen controller and a remote Arduino-based shutdown-request unit. The design aims to interface with an existing Murphy 117 and Swichgage safety circuit without replacing those protections.

Current status: A bench prototype has demonstrated touchscreen commands, bidirectional LoRa messaging, a three-second relay pulse, and simulated isolated trip-input feedback. The Murphy/engine interface and actual shutdown verification remain incomplete.

Innovation Claim

Low-infrastructure remote shutdown for agricultural wells

The project combines accessible embedded hardware, direct sub-GHz LoRa communication, a local touchscreen, and a planned interface to an existing Murphy shutdown system. It is intended to reduce trips to remote well sites during hazardous weather without requiring cellular service at the well.

Demonstrated

  • Two-way LoRa communication between Arduino Nano controllers
  • Nextion touchscreen shutdown command
  • Three-second relay actuation and acknowledgment
  • Isolated optocoupler input tested with a simulated 5 V signal

Still to validate

  • Safe, compatible Murphy 117 interface
  • Independent proof of engine stopped/running state
  • Radio range, interference resistance, and message authentication
  • Field power protection, weatherproofing, and complete cost estimate

Design & Wiring Overview

Current bench wiring and proposed field architecture. These are pin references, not a certified engine-control schematic.

Home Controller

  • Arduino Nano and Nextion Enhanced 3.5-inch display
  • Nextion TX → Nano D2; Nextion RX ← Nano D3
  • LoRa TXD → Nano D10; LoRa RXD ← Nano D11
  • Shared logic ground; regulated 5 V power

Well Controller

  • Arduino Nano and DX-LR32-900T22D UART LoRa
  • LoRa TXD → Nano D10; RXD ← Nano D11
  • Relay input IN1 → Nano D4 (active HIGH on tested board)
  • Optocoupler OUT → Nano D5 (active LOW with INPUT_PULLUP)

Planned Field Interface

  • Fused, automotive-rated 12 V to 5 V conversion
  • Relay dry contacts proposed for a shutdown request in parallel with existing protection, subject to verification
  • 3–5 V optocoupler input requires a correctly rated, isolated Murphy sensing interface
  • Existing Swichgage and emergency-stop functions must remain independent

Important: No direct connection from 12–13 V Murphy wiring to Nano D5 or the 3–5 V optocoupler input. A relay pulse acknowledgment is not proof that the engine has stopped.

Prototype Overview

  • Shows enclosure design and component integration
  • Displays simulated isolated input feedback; safety integration remains pending
  • Cost estimate pending a complete bill of materials

How the Bench Prototype Works

1. Touchscreen request

Nextion Enhanced touchscreen sends WELL_STOP to the home Arduino Nano.

2. LoRa command

Home Nano transmits a plain-text UART LoRa message. Authentication and encryption have not been implemented.

3. Relay pulse

Well Nano activates relay D4 for three seconds, then returns ACK_RELAY_PULSED. This does not confirm engine shutdown.

4. Simulated feedback

Bench optocoupler D5 state changes generate MURPHY_TRIPPED or MURPHY_RESET messages. Actual Murphy integration is pending.

Prototype Progress & Next Steps

  • Completed: Direct two-way LoRa link, touchscreen command, relay pulse and acknowledgment, simulated isolated input feedback, and firmware repository.
  • In progress: Murphy 117 shutdown-request and independent status-sensing interface design.
  • Not yet tested: Actual engine shutdown, engine RPM feedback, long-range radio performance, power transients, environmental durability, and authenticated control.

Safety: This is a student bench prototype, not a production-ready or safety-certified engine shutdown controller. Original shutdown protections must remain functional independently.

Technical Specifications — Tested Prototype

Controllers

Two Arduino Nano ATmega328P boards

Radio

DX-LR32-900T22D(T0), SX1262-based UART LoRa modules, configured near 915 MHz at 9600 baud UART

User Interface

Nextion Enhanced 3.5-inch NX4832K035 touchscreen

Relay

5 V relay board; D4 HIGH energizes relay for 3 seconds

Feedback

3–5 V input optocoupler; D5 active LOW; tested with simulated signal

Protocol

Direct UART LoRa messages: WELL_STOP, ACK_RELAY_PULSED, MURPHY_TRIPPED, MURPHY_RESET. No encryption/authentication implemented.

Range & Cost

Field range and final bill of materials not yet verified

Validation

Bench-tested electronics only; real engine shutdown, electrical transients, and fail-safe behavior not yet validated
