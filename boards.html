How My Projects Fulfill the Objectives

My portfolio demonstrates achievement across all six objectives:

📱 Remote Irrigation Well Control System (Student Innovation Project)

This is my primary capstone project that demonstrates expertise in multiple objective areas:

  • Obj 1: Combines Arduino microcontrollers with LoRa modules to create an embedded IoT solution addressing real-world irrigation control challenges
  • Obj 2: Demonstrates microprocessor design, circuit implementation, relay control, power management, and encrypted LoRa communication protocols
  • Obj 3: Integrates actuators (relay), transducers, sensing (Murphy switches), and mechanical actuation into an irrigation system
  • Obj 4: Analyzes agricultural robotics applications, cost optimization ($300 vs $2000-5000 commercial solutions), power efficiency (6+ month battery life)
  • Obj 5: Models and designs an integrated system combining software logic, wireless communication, and hardware control for autonomous well operation
  • Obj 6: Establishes foundation for AI/data systems through sensor data tracking and predictive maintenance capabilities

🤖 Swappy Rover Project

This secondary project demonstrates expertise in complementary objective areas:

  • Obj 1: Designs a modular robotics platform with interchangeable components and autonomous capabilities
  • Obj 3: Implements mechanical control through motor systems, transducers, and multi-sensor feedback integration
  • Obj 4: Assesses robotics applications across research, education, and field operations with focus on modularity and scalability
  • Obj 5: Integrates hardware (motors, sensors) with software (Arduino control logic) for autonomous operation and remote control
