Student Innovation Project (SIP)

Well Killer — LoRa Remote Irrigation Well Shutdown

Project Overview

Well Killer is a prototype designed to let an irrigation operator request a remote well shutdown during hazardous weather without traveling to the well site. The current prototype demonstrates two-way wireless commands, relay activation, and simulated Murphy switch status feedback. An actual engine shutdown has not yet been tested.

Problem & Approach

When storms threaten an irrigated field, operators may need to shut down remote wells quickly to avoid flooding crops or causing equipment damage. Reaching a well in lightning or severe weather introduces a safety risk, while some agricultural sites have poor cellular coverage.

Project Goal

Develop a locally controlled, long-range radio shutdown system using Arduino microcontrollers and LoRa modules. The goal is to send a shutdown request from a home station and receive meaningful feedback from the well-side equipment without relying on cellular service or a cloud subscription.

Safety boundary: The system is intended to interface with an existing Murphy shutdown arrangement, not replace the engine's independent protective controls. Live-engine integration requires appropriate electrical verification and safe testing.

Innovation Claim

Practical Remote Shutdown for Cellular Dead Zones

The project combines a local touchscreen interface, two-way LoRa communication, and an isolated relay interface to explore a lower-infrastructure alternative for remote irrigation well control.

Design Priorities

  • Local radio communication without internet or cellular service
  • Touchscreen control from the home station
  • Confirmation that a relay command was executed
  • Status feedback from a well-side input

Still to Validate

  • Real-world radio range and reliability
  • Installed power consumption and weatherproofing
  • Safe integration with the Murphy switch
  • Verified engine shutdown and feedback
  • Final bill of materials and cost comparison

Current Prototype Progress

Bench-tested functionality as of November 2026. Results below distinguish confirmed actions from proposed operation.

✓ Two-Way LoRa Communication

The home and well-side Arduino Nano units exchange commands and response messages through UART LoRa modules.

✓ Touchscreen Shutdown Request

A Nextion touchscreen sends a WELL_STOP command from the home unit to the well unit.

✓ Relay Pulse and Acknowledgment

The well unit activates its relay for approximately three seconds and replies ACK_RELAY_PULSED. The home display reports “RELAY ACTIVATED,” not “ENGINE STOPPED.”

✓ Simulated Status Feedback

A simulated optocoupler input produces MURPHY_TRIPPED and MURPHY_RESET messages, which update the home station.

○ Live Murphy Integration

The relay has not yet been tested as part of a complete, installed engine shutdown circuit.

○ Field Validation

Radio range, installed electrical behavior, actual engine-stop confirmation, and long-term reliability remain unverified.

The current architecture uses two Arduino Nano stations and serial-connected LoRa radios. The diagram below describes the tested bench arrangement; it is not a complete electrical schematic.

Shutdown Interface — Proposed

The intended design uses an isolated relay contact in parallel with the manual Murphy shutdown trigger. The relay pulse is bench-tested; the full Murphy/engine connection is not yet tested.

Optocoupler Safety Note

The current optocoupler module is rated for 3–5 V input and was tested using isolated 5 V. It must not be connected directly to the 12–13 V Murphy circuit without an appropriately designed interface.

Technical Details

Controllers

Arduino Nano at the home and well stations

Radio Hardware

DX-LR32-900T22D(T0), SX1262-based UART LoRa modules

Radio Configuration

915.150 MHz; bandwidth setting 6; spreading factor 11; coding rate setting 1; CRC enabled; IQ setting 1; transmit power setting 22 dBm

Home Interface

Nextion Enhanced 3.5-inch touchscreen, NX4832K035

Shutdown Output

Active-HIGH relay input on well-side D4; approximately 3-second bench-tested pulse

Status Input

Optocoupler output to D5, active LOW; simulated 5 V test input only

Communication

Local point-to-point LoRa messaging over UART; not LoRaWAN

Security & Reliability

Encryption, command authentication, operational range, and production failsafes have not been established

Next Steps

  1. Document and verify the full wiring schematic, power distribution, and electrical isolation.
  2. Develop an appropriate voltage-safe interface for the actual Murphy status circuit.
  3. Test the relay and Murphy shutdown connection under controlled, supervised conditions while preserving independent engine protections.
  4. Confirm engine-stop feedback separately from relay acknowledgment.
  5. Measure radio range, power use, and failure behavior before considering field deployment.

Project status: Working bench prototype; not yet validated as an installed, production-ready well shutdown system.
