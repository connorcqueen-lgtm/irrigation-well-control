Educational Objectives

Robotics & Embedded Systems — Boards Portfolio

Boards is a separate graduation portfolio from my Student Innovation Project (SIP). Each of the six program objectives requires evidence from two distinct projects. A single project may support no more than two objectives. The assignments below are proposed evidence selections, not yet faculty-approved completions.

Boards Objectives and Project Evidence

Each objective is followed by two projects and an explanation of how the work demonstrates that objective. Project selections are proposed pending faculty review. Objective wording below is retained from the existing site; verify against the official program rubric before final submission.

Objective 1

Design and complete robotic and embedded systems solutions that address real-world situations and challenges.

Project 1: Well Killer SIP

The system addresses the real agricultural problem of needing to shut down irrigation wells during dangerous weather without approaching equipment during lightning. I designed and assembled a home controller, LoRa communication link, and well-side relay controller, then bench-tested the touchscreen shutdown command, relay pulse acknowledgment, and simulated Murphy input feedback. This demonstrates a practical embedded solution through requirements, integration, and iterative testing; actual engine shutdown remains unverified.

View related SIP evidence

Project 2: Arduino Robotic Arm

I designed and assembled a 3D-printed robotic mechanism integrating an Arduino Uno, servo and stepper control, joystick input, ultrasonic ranging, and a tilt switch. I selected component connections, resolved power and wiring faults, and tested motor and sensor subsystems. The project demonstrates the process of designing and completing an embedded robotic prototype, while full-load shoulder performance still needs validation.

Watch demonstration on YouTube

Objective 2

Demonstrate embedded microprocessor system and circuit skills.

Project 1: Arduino Robotic Arm

I configured Arduino Uno digital and analog pins for motor commands, joystick input, ultrasonic distance measurement, tilt sensing, and warning output. Integrating separate regulated motor power with a shared ground and troubleshooting wiring faults demonstrates practical microprocessor interfacing, circuit design, and debugging.

Watch demonstration on YouTube

Project 2: Four-Bit Seven-Segment Display

I programmed the Arduino to read four digital inputs as a binary number, calculate values from 0 to 15, and drive seven display segments using active-low output patterns. This demonstrates digital I/O configuration, logic-level interpretation, circuit wiring, and translating software values into electronic outputs.

Watch demonstration on YouTube

Objective 3

Develop mechanical control systems by implementing transducers, actuators, feedback, vision and sensing systems, and other mechanical systems into robotic platforms.

Project 1: L293D Motor Control and PWM Lab

I interfaced an Arduino with an L293D dual H-bridge to command the direction and speed of two DC motor actuators. The program independently ramps speed forward and backward using PWM, demonstrating software control of electromechanical motion. This was open-loop control, not closed-loop feedback.

Watch demonstration on YouTube

Project 2: Potentiometer and Photoresistor Sensor Lab

I used the Arduino analog-to-digital converter to read adjustable resistance and ambient-light sensor signals, selected the active input with a digital switch, and mapped sensor readings to LED outputs. This demonstrates sensor acquisition and responsive embedded control logic, although the lab did not itself actuate a mechanical joint.

Watch demonstration on YouTube

Objective 4

Examine and assess a variety of applications within the field of robotics.

Project 1: Well Killer SIP

I evaluated remote irrigation control as an application of embedded automation, considering the limitations of cellular coverage, the use of LoRa for remote communication, and the need to preserve the existing Murphy safety mechanism. Bench testing also helped distinguish command acknowledgment from verified engine shutdown. This evaluation identifies operational benefits, limitations, and safety tradeoffs.

View related SIP evidence

Project 2: Arduino Sensor Lab

I compared how sensor input can be interpreted and used by a microcontroller to trigger output behavior, considering where proximity, tilt, or environmental sensing can support robotics applications. To fully substantiate this objective, I still need to add a written comparison of alternative sensors, limitations, and appropriate use cases.

Objective 5

Model, analyze, and design systems or processes that integrate hardware and software to control autonomous mechanical systems.

Project 1: Simon Says Arduino Game — Candidate

I designed a self-running sequence generator that coordinates programmed LED outputs with user-button input, state tracking, and correctness checks. This demonstrates hardware/software coordination and automatic sequencing; however, the project does not control an autonomous mechanical system, so it may not satisfy the full objective without additional work.

Watch demonstration on YouTube

Project 2: L293D Motor Control Lab — Candidate

I implemented a programmed sequence of motor acceleration, stopping, reversal, and deceleration without continuous user input. This demonstrates integrated software-driven mechanical motion, but the lab lacks sensing, decision-making, and a broader autonomous-system model. Additional evidence or a replacement project may be needed.

Watch demonstration on YouTube

Objective 6

Implement artificial intelligence and data systems into robotic platforms.

Project 1: Local AI Voice Interface — Planned

Assignment 4.1 will develop a local assistant that can accept spoken input and produce spoken responses. To demonstrate this Boards objective, I plan to map a limited set of interpreted voice commands to safe, predefined robotic actions and document the interface and testing. This robotics integration has not yet been completed.

Project 2: Local AI Vision Interface — Planned

Assignment 4.2 will add visual input to a local AI assistant. I plan to use visual recognition output as input to a robotic control decision or simulation and record test results. The coursework and robotics integration are still in progress; no completed implementation is claimed here.
