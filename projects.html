Featured Project

My main project focuses on using embedded systems and LoRa communication to solve a real agricultural safety problem.

Remote Irrigation Well Control System

This project is a LoRa-based remote control system designed to allow irrigation wells to be shut down from a safer location. The goal is to reduce unnecessary travel to remote well sites during hazardous weather, emergencies, or difficult field conditions.

Project Type Senior Innovation Project / Embedded IoT System
Main Technology Arduino microcontrollers with LoRa communication
Purpose Remote irrigation well shutdown and control
Focus Safety, reliability, affordability, and long-range communication

Long-Range Control

Uses LoRa communication to send commands between a home/control station and a remote well site.

Embedded Hardware

Uses Arduino-based control logic with relay hardware to interact with physical irrigation equipment.

Real-World Safety

Designed to reduce the need for operators to drive to well sites during unsafe conditions.

Affordable Design

Focuses on a practical, lower-cost alternative to expensive commercial remote control systems.
