🚰 Remote Irrigation Well Control System

Project Status: Student Innovation Project (SIP) | Primary/Featured Project

A LoRa-based remote control system designed to allow irrigation wells to be shut down from a safer location. This system addresses a real agricultural safety problem by enabling operators to control wells remotely without traveling to dangerous remote sites during hazardous conditions.

Project Type Student Innovation Project / Embedded IoT System
Main Technology Arduino microcontrollers with LoRa communication
Purpose Remote irrigation well shutdown and control
Cost Under $300 (10x cheaper than commercial solutions)

Long-Range Control

Uses LoRa communication to send commands between a home/control station and a remote well site (10-15 mile range).

Embedded Hardware

Uses Arduino-based control logic with relay hardware to interact with physical irrigation equipment.

Real-World Safety

Designed to reduce the need for operators to drive to well sites during unsafe conditions like storms.

Off-Grid Operation

Completely independent - no internet, cellular, or cloud dependency required.

🤖 Swappy Rover

Project Status: Robotics Project | Secondary Project

A modular wheeled robotics platform designed with interchangeable components and attachments. The Swappy Rover demonstrates principles of mechanical design, sensor integration, and autonomous control systems suitable for various applications including research, education, and field operations.

Project Type Robotics Platform / Mechanical Design
Main Technology Arduino microcontrollers with motor control and sensor feedback
Purpose Mobile robotics research and autonomous platform development
Focus Area Modularity, scalability, and multi-sensor integration

Modular Design

Interchangeable components allow for different sensor configurations and attachment systems.

Multi-Sensor Integration

Combines multiple sensors for navigation, obstacle detection, and environmental awareness.

Control Systems

Programmable Arduino-based control for autonomous and remote-controlled operation.

Scalable Platform

Design allows for expansion and integration of additional systems and capabilities.
